CACHE STATISTICS:
-----------------
The cache automatically tracks:
  - Cache hits (models retrieved from cache)
  - Cache misses (models loaded from disk)
  - Hit rate percentage
  - Number of models cached
  - Number of evictions (LRU policy)

Example usage:
  from clipsai.utils.model_cache import ModelCache
  cache = ModelCache.get_instance()
  stats = cache.get_stats()
  print(f"Hit rate: {stats['hit_rate_percent']:.1f}%")
